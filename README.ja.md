## これは何か

早く寝たい、本を読みたい、運動したい——分かっているのに続かない。

Habit は「続けること」を見える数字に変えます：

- **達成するたびに加点**、サボるたびに減点
- 貯まったポイントは**自分で決めた小さなご褒美**と交換できる（ドラマ1話、ミルクティー、二度寝）
- 連続達成で**実績**が解放され、**連続日数**として記録される
- 習慣データはすべて端末内。ログインは身分確認とフィードバックのみで、**クラウド同期はしません**

## 機能

### プラン管理

- プラン作成：名前、信念、きっかけ、達成時の加点、失敗時の減点、開始日
- カード上で直接 **加点 / 減点**（🎉 と 💪 の演出つき）
- 連続加点カウント（減点でリセット）と過去最長の記録
- 編集・削除（削除時はポイントも消える旨を警告）

### ポイントとストア

- 合計ポイント = 全プランのポイント + 単発タスクの報酬 − 交換済み
- ストアの**ご褒美は自分で作る**：何と交換するか、何ポイント必要かも自由
- 交換は確認ダイアログつき、ポイントは即時反映

### 実績

| 実績 | 条件 |
|---|---|
| はじめの一歩 | 1つのプランで連続10回達成 |
| 自律の専門家 | 1つのプランで連続100回達成 |
| 自律の達人 | 1つのプランで連続1000回達成 |
| 自律の神 | 全プラン合計で連続5000回達成 |

解放後は永久に残り、リセットして再挑戦もできます。

### ツール

- **ポモドーロ**：25分集中 + 5分休憩。時刻が来るとシステムのアラームで鳴る。画面を離れても計測は継続
- **記憶カード**：自作の質問/回答カードをめくって復習
- **アイゼンハワーマトリクス**：重要 / 緊急の4象限。単発タスクと同じデータを共有

### 単発タスク

- 1回きりのタスク：完了すると取り消され、すぐ加点
- **期限**（過ぎると赤字）と**リマインダー時刻**（システムアラーム、通知に「停止」ボタン）を設定可能
- 期限順に並び、近いものが上に
- **自動で緊急扱い**：設定で N 日を選ぶと、期限が近い非緊急タスクは自動で緊急の象限へ移動（元に戻せる）
- リストは折りたたみ可能。閉じているときは `🔥 緊急数 / 未完了数` を表示

### アカウントとフィードバック（任意）

- Supabase で認証。ユーザー名は `ユーザー名@habit.local` に変換される
- ログイン中は**アプリ内から直接作者にフィードバックを送れる**（メール不要）
- ログイン前に**スライダー式の確認**
- **クラウド同期はしません**：データは端末内のみ。「設定 → データとバックアップ」から JSON で書き出せます

### その他

- **5言語**：简体中文 / 繁體中文 / English / 日本語 / Русский
- **ダーク / ライト / システムに従う**
- ダイナミックカラー（Android 12+ の壁紙色）
- 利用規約・プライバシーポリシー・オープンソースライセンス（多言語の閲覧ページ）

## 3つのイースターエッグ

<details>
<summary>⚠️ ネタバレあり。自分で探したい人は開かないでください</summary>

<br/>

**① 何見てるの**

`マイ → イースターエッグ` は真っ白な画面で、🙃 と一言だけ。
顔はゆっくり浮遊し、5回タップすると素を出します（🙃 → 🤪）。出口もそこに現れます。

**② 何かが変わった気がする**

前提：**① を訪れた** かつ **「はじめの一歩」を解放**。

「プラン」画面の左上のアプリアイコンを3回タップ（毎回振動）、3回目でヒントが出ます。

**③ 冬が来た**

② のあと、「マイ」の**任意の行**をタップすると画面が乗っ取られます：

> 暗転から明転 → 雪の夜、月、松林、灯りのともる山小屋 → 雪が降り出す
> → 四行の詩が縦書きで一文字ずつ浮かぶ
> → 落款の印 → ゆっくり暗転、計 18.5 秒

**画像素材は一切使っていません**。すべて `Canvas` の手描き：空のグラデーション、星の瞬き、月のクレーター、遠景の山、雪を載せた松、煙、雪の粒子、窓の暖かい光。

## ビルド

**必要なもの**：JDK 21 以上、Android SDK 37

```bash
# デバッグ版（そのままインストール可）
./gradlew assembleDebug
# 出力：app/build/outputs/apk/debug/app-debug.apk

# リリース版（署名は自分で用意）
./gradlew assembleRelease
```

### 署名について

リポジトリに署名鍵は**含まれていません**。リリース版を作るには自分の keystore を生成してください：

```bash
keytool -genkeypair -v -keystore habit-release.jks \
  -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 \
  -alias habit -storepass <パスワード> -keypass <パスワード> \
  -dname "CN=YourName, OU=Habit, O=YourName, C=CN"
```

その後 `app/build.gradle.kts` の `signingConfigs` を自分のパスとパスワードに変更します。

> **keystore を失うと、このアプリを二度と更新できません**——同じパッケージ名の新バージョンは同じ鍵で署名する必要があります。必ず別途バックアップを。

## 補足

- 連絡先・写真・位置情報は取得しません。広告も解析もありません。ネットワーク権限はログインとフィードバックのみに使用
- アンインストールやデータ削除で記録は永久に消えます
- 実機（Honor BKQ-AN10 / Android 17）で全機能を検証済み
