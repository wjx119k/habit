## Что это

Хочется раньше ложиться, больше читать, двигаться — всё понятно, но держаться трудно.

Habit превращает «держаться» в цифры, которые видно:

- **Каждое выполнение даёт баллы**, каждый срыв их отнимает
- Баллы можно **обменять на маленькие награды, которые вы придумали сами** (серия, молочный чай, утро без будильника)
- Серии открывают **достижения** и записываются как **дни подряд**
- Данные привычек хранятся на телефоне. Вход нужен только для идентификации и отзывов — **облачной синхронизации нет**

## Возможности

### Планы

- Создание плана: название, убеждение, повод, баллы за выполнение и за срыв, дата начала
- **+ / −** прямо на карточке, с поддерживающими эффектами
- Счётчик серии (сбрасывается при срыве) и лучшая серия за всё время
- Редактирование и удаление (при удалении предупреждаем, что баллы исчезнут)

### Баллы и магазин

- Всего = сумма баллов планов + награды за разовые задачи − потраченное
- **Награды создаёте вы сами** — что обменять и сколько это стоит
- Обмен с подтверждением, баллы обновляются сразу

### Достижения

| Достижение | Условие |
|---|---|
| Первые шаги | 10 выполнений подряд по одному плану |
| Дисциплина | 100 выполнений подряд по одному плану |
| Мастер | 1000 выполнений подряд по одному плану |
| Легенда | 5000 выполнений подряд по всем планам |

Открытые достижения остаются навсегда; можно сбросить и начать заново.

### Инструменты

- **Помодоро**: 25 минут фокуса + 5 минут отдыха, звонок через системный будильник; отсчёт продолжается при уходе с экрана
- **Карточки памяти**: свои вопросы и ответы, переворачивание для повторения
- **Матрица Эйзенхауэра**: квадранты «важно / срочно», общие данные с разовыми задачами

### Разовые задачи

- Одноразовые задачи: отметил — сразу получил баллы
- Можно задать **срок** (просрочка красным) и **время напоминания** (системный будильник, в уведомлении есть кнопка «Остановить звонок»)
- Сортировка по сроку: ближайшие сверху
- **Авто-срочность**: в настройках выбирается N дней; несрочные задачи со сроком в пределах N дней автоматически переходят в срочный квадрант (обратимо)
- Список сворачивается; в свёрнутом виде показывает `🔥 срочных / открытых`

### Аккаунт и отзывы (по желанию)

- Аутентификация через Supabase; имя пользователя превращается в `имя@habit.local`
- После входа можно **отправить отзыв прямо из приложения** — без почтового клиента
- Перед входом — проверка ползунком
- **Облачной синхронизации нет**: данные только на устройстве; экспорт JSON в «Настройки → Данные и резервная копия»

## Сборка

**Требуется**: JDK 21+, Android SDK 37

```bash
# Отладочная сборка (можно ставить)
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk

# Релизная сборка (нужен свой ключ подписи)
./gradlew assembleRelease
```

### О подписи

В репозитории **нет** ключа подписи. Для релиза создайте свой keystore:

```bash
keytool -genkeypair -v -keystore habit-release.jks \
  -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 \
  -alias habit -storepass <пароль> -keypass <пароль> \
  -dname "CN=YourName, OU=Habit, O=YourName, C=CN"
```

Затем укажите путь и пароль в `signingConfigs` в `app/build.gradle.kts`.

> **Потеряете keystore — больше не сможете обновлять приложение**: Android требует один и тот же ключ для всех версий одного пакета. Сделайте отдельную резервную копию.
